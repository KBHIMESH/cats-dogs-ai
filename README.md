# Cat vs Dog Classifier

Live App: https://cats-dogs-aigit-fkavgkfxyncxjsjzr5dv6d.streamlit.app/

This app predicts if an image is a cat or dog using AI.

Model: MobileNetV2
Accuracy: 98.3%
Tech: Python, TensorFlow, Streamlit

How to run locally:
pip install -r requirements.txt
streamlit run app.py
